Elysium es un sitio web dirigido a los amantes de los libros.
Descripción: Elysium es un sitio web para que los amantes de los libros puedan dar su opinion sobre las lecturas que tienen, tambien si buscan algo nuevo pueden ver recomendaciones y los comentarios de los demás para darse una pequeña idea de lo que trata el libro.

Características: Elysium cuenta con un apartado para poder publicar opiniones, reseñas o recomendaciones, se puede comentar en estas publicaciones, se les puede dar like también.

Funciones: Al momento de dirigir el mouse a alguna publicación, esta se resaltara con una luz tenue de color blanco, algo similar pasa con lasfotos de perfil, a estas se les crea un circulo al rededor un poco más opaco.
Las funciones de las publicaciones y comentarios: se les puede dar like a las publicaciones y comentar. En la parte del perfil del usuario se puede colocar un banner y se puede cambiar la foto de perfil.

Datos extra: Elysium esta inspirada en muchos sitio webs, principalmente en Discord, utiliza una paleta de colores oscura con tonalidades de grises.
